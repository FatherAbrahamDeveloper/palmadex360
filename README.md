# Palmadex 360

Export management platform for Palmadex Global Integrated Services Ltd.

- `client/` React + Vite frontend (deployed on Vercel)
- `server/` Node.js + Express + Prisma API on PostgreSQL (deployed on Render, database on Neon)
- `docs/deployment-guide.md` how to deploy and run locally
- `docs/platform-guide.md` what the platform does, including quality checks (QA/QC) in Procurement
